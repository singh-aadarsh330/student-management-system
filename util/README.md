# 🛠️ Utility Layer: Cross-Cutting Validation

The utility layer provides centralized, stateless validation logic to ensure data integrity across the entire system.

## 📁 Files
- `ValidationUtil.java`: Static utility class for business rule enforcement.

## 🛡️ Validation Rules
- **Email**: Regex-based check for `@` and domain extensions.
- **Marks**: Numeric range validation for academic scores.
- **Age**: Compliance check with institutional age policies.
