# Contributing to Student Management System

We welcome contributions to improve the academic registry system!

## 🚀 Workflow
1. **Fork** the repository.
2. **Clone** your fork.
3. **Branch**: `git checkout -b feature/your-feature-name`
4. **Commit**: Ensure your commit messages are descriptive.
5. **Push**: `git push origin feature/your-feature-name`
6. **Pull Request**: Open a PR for review.

## 🎨 Style Guide
- Follow **Google Java Style Guide**.
- Maintain **Strict Encapsulation** in model classes.
- Use **Layered Architecture** principles.
